# FifthAvenue Media website

A responsive five-page static website prototype for a technology-led marketing and growth studio.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `results.html` — Results and performance measurement
- `contact.html` — Contact form and email path

Open `index.html` in a modern browser to begin. The site has no build step or package dependencies. Google Fonts load when online; system fallbacks are included.

## Design and interactions

The system follows the supplied references: black, white, cobalt, and violet; luminous gradients; large editorial headings; alternating light and dark sections; asymmetric bento layouts; sticky liquid-glass story cards; and scroll reveals that respond in both directions. A silver outline intro, rolling text separators, pointer-reactive emblem, and looping 3D service deck add motion between the core sections. Reduced-motion preferences are supported.

The supplied logo reference has been reimagined as a silver, beveled 3D emblem with cobalt-violet studio lighting. The mockup appears in the shared wordmark and selected section accents. The earlier motion clip is retained in `assets/` as a supplied visual reference.

## Before publishing

The `100%`, `£40m`, and `10 years` figures are sample placeholders adapted from the supplied visual reference. Replace them with verified FifthAvenue/client results and attribution. Confirm the proposed `hello@fifthavenuemedia.com` address and domain before launch. The contact form opens an email draft; it does not send data to a website backend.
